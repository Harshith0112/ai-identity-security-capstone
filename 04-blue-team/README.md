# 04-blue-team

## Objective
Implement defensive security controls to protect
SecureNova AI identities and services.

## Security Controls
- Input and output guardrails
- JWT credential redaction
- Ed25519 agent identity verification
- Auth0 token lifetime hardening
- Refresh-token rotation
- Anomaly detection
- Before-and-after attack comparison

## Evidence
- Guardrail test outputs
- JWT redaction results
- Ed25519 verification results
- Auth0 configuration screenshots
- Refresh-token replay test
- Anomaly detection alerts
