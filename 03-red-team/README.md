# 03-red-team

## Objective
Simulate attacks against AI identity systems and
evaluate their security impact.

## Attack Scenarios
- Indirect prompt injection
- Agent identity spoofing
- System prompt extraction
- RAG knowledge poisoning
- MCP abuse

## Security Activities
- Attack payload development
- Attack simulation
- CVSS 3.1 scoring
- MITRE ATLAS mapping
- Attack success-rate analysis

## Evidence
- Attack scripts
- Terminal outputs
- CVSS findings
- Risk assessment
